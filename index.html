Decode AWC streams locally, verify them, then sync them to Project Strike in small category commits that GitHub can actually process.

2. Sync categories to FPS Game

Resident is automatically split into its existing categories: collision, collisions, explosions, melee and weapons. Each selected category is committed in small chunks, so a 1,795-file import cannot fail at one giant final tree.

Matching file paths are replaced. New paths are added. Completed chunks are committed immediately, so if a later category fails you can re-run safely without losing the categories that already finished.

3. ZIP backup

Optional backup only. Direct category sync is the recommended iPhone workflow.

The game audio root remains exactly three layers: weapons_player, dlc_weapons and resident. Resident then contains its real bank categories underneath.

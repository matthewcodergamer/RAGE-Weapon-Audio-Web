2. Upload directly to FPS Game

This avoids iPhone ZIP extraction completely. Every verified stream is converted independently, uploaded as a Git blob, and then all paths are committed to the game repository in one commit.

Auto Detect reads the selected folder/path first. If iPhone/Safari strips the folder path, choose the correct layer manually here before uploading.
Only three destination layers are allowed: weapons_player, dlc_weapons, and resident. The token is never saved to this repository or localStorage.

3. ZIP backup

ZIP remains available as a backup. GitHub upload is the recommended iPhone workflow.

GitHub layout: public/game-assets/audio/weapons_player, dlc_weapons, and resident. Each AWC bank gets its own subfolder so the runtime can map weapon banks cleanly.

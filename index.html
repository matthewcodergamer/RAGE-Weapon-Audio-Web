RAGE Weapon Audio Web

Real browser-side GTA V AWC extraction for weapon banks. PCM and Rockstar IMA ADPCM are decoded locally; unsupported/encrypted layouts are rejected instead of exporting noise.

1. Choose AWC audio

Select a whole extracted folder or many .awc files. The parser validates each bank before export.

2. Export all audio

One button converts every valid stream and creates a flat ZIP. After opening it, every WAV is directly inside audio/ — no folder per bank or per sound.

Output: Project-Strike-Audio/audio/*.wav plus audio-manifest.json. Filenames include the original AWC bank name and stream hash, so the folder can be dragged directly into the game project without collisions.

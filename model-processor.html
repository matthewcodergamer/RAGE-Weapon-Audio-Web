Review the auto-classification first. Converted runtime GLBs go into public/game-assets/models/.... Blender source files go to assets-source/blend/ and the FPS repository's Blender workflow exports their GLBs. Related source textures are only uploaded when required by a source asset.

Real conversion rules

GLB: parse → validate → upload unchanged. glTF: resolve BIN/textures → parse → GLTFExporter → GLB. FBX: FBXLoader → real Three.js scene → GLTFExporter → GLB. ZIP: extract locally first, then process its contents. BLEND: source upload → GitHub Action → headless Blender → real GLB. If parsing or conversion fails, the asset is marked failed and is not silently uploaded as a fake GLB.
